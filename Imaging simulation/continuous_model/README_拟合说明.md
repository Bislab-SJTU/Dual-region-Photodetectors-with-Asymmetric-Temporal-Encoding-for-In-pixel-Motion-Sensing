# 200 Hz、0°、10%和50%光强的连续动态拟合

仅使用当前阵列模拟的两种参考条件。各条件以cycle_1.csv对应完整实测周期拟合；另外20个同条件周期仅用于比较，没有加入拟合。没有扩大到其他频率、方向或光强，也没有使用神经网络识别正确率作为拟合目标。

## 模型定义

采用4个带延迟的归一化动态状态：

`dq_j/dt = (u(t-d_j)-q_j)/tau_j`，充电和放电使用分别拟合的正时间常数；`I = b + sum(a_j*q_j)`。

u为0到1的归一化照明驱动；拟合假设200Hz、50%占空比，周期5ms、亮段2.5ms。没有同步光信号，本次将输入相位与响应延迟合并拟合。

状态在物体离开后继续衰减，相邻事件不清零；偏置b保留暗态电流，不把恢复尾部截成零。系数允许正负以描述稳态和瞬态的合成响应；负系数不表示负电容。

拟合包含延迟、充放电速率不对称以及多个恢复时间尺度。参数保存于fitted_parameters.json。此前相同充放电速率的线性模型保存在“线性模型对照”文件夹。

## 参数解释与使用范围

这是实测约束的经验动态模型，不是唯一等效电路。只用一个频率的波形不能唯一分离电阻、电容、载流子过程和空间响应的影响，因此tau不能直接解读为测得的RC常数，也不能据此反推出R或C。

拟合延迟包含周期参考起点到响应发生的相位，以及可能的两区空间时序；它不等于单独的器件本征延迟。后续接入阵列时，必须先对齐光照驱动的时间原点，避免把已有空间扫过时间重复计入。不同运动方向、照明持续时间或光强连续变化的准确性尚未验证。
