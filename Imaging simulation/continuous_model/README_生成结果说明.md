# 汽车阵列模拟：连续动态混合响应（第140周）

只生成亮度变化场景。沿用第132周保存结果对应的汽车图片、100×100像素排列、运动轨迹、方向、速度、时间轴以及列50处的光强切换。混合响应改为刚拟合的连续动态状态模型；稳态响应按原稳态参考波形和原分段算法重新生成。

## 数据量与结构

- `result/亮度变化/混合响应/pixel_waveforms/`：10,000个CSV，名称仍为pixel_行_列.csv；列仍为Time_s、Current_A，单位秒和安培。
- `result/亮度变化/稳态响应/pixel_waveforms/`：10,000个同结构的稳态对照CSV。
- 每像素15689个采样点；起点0，终点约0.15688s；实际步长见manifest.json，沿用原linspace时间轴。
- 每种响应的`frames/`：79帧、frame_0000.png至frame_0078.png，沿用上一版普通阵列色图的像素比例和Blues色表，幅值色标0–135µA。
- 每种响应另有`array_current.gif`、`array_current.mp4`和`five_frame_current.png`。
- 每种响应的`array_current_A.npy`：完整电流快速读取缓存，float32，维度为[行,列,时间]。CSV保留12位有效数字，float32缓存有约1e-11A量级舍入误差。
- `光照场景/`：汽车输入场景的79帧、light_motion.mp4和GIF。输入图为原透明汽车图片在原像素采样点处的照明采样，不是彩色摄影视频。
- `illumination_events.csv`：16200个真实几何光照进入/离开事件，包含像素坐标、索引及时间；后续网络截窗应使用此表。
- `pixel_status.csv`：全部像素的受光事件数量；其中6400个像素发生过受光事件。
- `time_s.npy`、`time_axis.csv`、`frame_times.csv`：时间轴和视频帧对应采样索引。
- `occluded_pixels.csv`为空表；亮度变化场景未加入遮挡区域。
- `reference_waveforms/`：原参考波形副本；`code/`：生成脚本、拟合脚本、参数和汽车图片。
- `新旧模拟波形与恢复尾部对比.png`：典型像素的完整响应及离开后的尾部。
- `output_verification.csv`：文件数、波形长度、有限性和电流范围检查。

## 场景与动态模型

方向0°向右，速度7330.4mm/s；左侧列0–49使用50%参考条件，右侧列50–99使用10%参考条件。200Hz是拟合参考波形的采集条件，不是任意汽车边缘经过像素时的周期频率。

照明遮罩继续采用原生成器的点采样、完全不透明像素规则，避免同时改变空间模型。没有额外加入子区域面积积分。拟合模型是整个混合像素的经验响应，因此没有重复叠加子区域空间延迟。

拟合参数中的延迟包含原参考周期的相位。接入阵列时统一减去0.000716s参考锚点，把原模拟器的受光事件起点映射到相同响应起点；各状态之间的相对延迟保留。连续积分器已与拟合模型的周期解析结果核对一致。

每个状态在进入、离开和后续事件之间连续演化，不重置、不强行截断恢复尾部。暗态偏置保留，所以“无受光事件”像素的混合响应电流也可能非零；不能再用Current_A!=0判定有没有事件。CSV保留正负电流，色图为便于与旧版对比仍显示电流绝对值。

稳态对照没有套用混合响应的拟合参数。原稳态分段模型在抽查像素上与旧CSV逐点一致。

## 检查与范围

1. 6个覆盖背景、两种光强、单事件及多事件的像素，其受光起点与旧混合响应CSV一致；旧稳态对照也已逐点核对。
2. 连续状态求解器与周期解析解的误差小于1e-5µA。
3. 两组各10,000个CSV、各79个普通电流图帧已确认；完整电流缓存检查全部有限，无NaN/Inf。
4. 典型导出CSV已回读核对列名、采样数、时间轴和电流缓存。

本次生成阵列数据和普通电流图，尚未进行神经网络或光流推理。旧版frame_pngs和matched_array.png属于识别/模板匹配后的结果，不作为新模型的预测复制过来。输出帧数量和时间表对应旧版15fps阵列色图；视频时间缩放比例为0.03。

连续模型仅用200Hz、0°、两种光强的实测周期拟合。汽车中的长平台、短间隔等属于该模型的外推，不能仅凭波形平滑宣称得到独立实验证实。模型参数是经验状态参数，不是唯一确定的器件R、C。

原第132周数据、前面的双边沿和仅上升沿识别结果均保留。生成脚本写入此新结果文件夹；再次运行会更新其中的数据。
